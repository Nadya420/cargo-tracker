# Проверка учебного прототипа

Дата: 20 ноября 2026 года. Проверены локальные исходники и опубликованная браузерная версия GitHub Pages.

## Серверная версия

Команда: `python3 -m unittest -v test_server.py`.

Финальный повторный прогон: **6 тестов пройдены, 0 ошибок**. Тесты запускают настоящий HTTP-процесс с временной SQLite и не используют рабочую базу приложения.

| Группа | Подтверждённое поведение |
|---|---|
| Авторизация | 401 без входа, отказ при неверном пароле, вход/выход, HttpOnly и SameSite=Strict для cookie |
| Изоляция | Чужие записи отсутствуют в списке и CSV, нельзя прочитать или изменить чужую карточку через API |
| Карточка и история | Создание, отклонение дубликата у владельца, обновление, журнал от новых событий к старым |
| CSV | Семь колонок, UTF-8 BOM, кириллица, кавычки, разделитель, нейтрализация префиксов формул |
| Проверка запросов | Неверные поля, JSON, MIME, размер тела и сторонний Origin отклоняются без создания записи |
| Сохранность | SQLite переживает перезапуск, demo не дублируется, пароль хранится как хеш |

Через браузер ранее проверены вход, создание, поиск, фильтр статуса, обновление и история. Реальные снимки: `registry.jpg`, `create.jpg`, `history.jpg`.

## Браузерный адаптер для GitHub Pages

Команда: `node --test test_browser_demo.cjs`.

Результат: **8 тестов пройдены, 0 ошибок**. Проверяется адаптер с контролируемыми localStorage/sessionStorage и Web Crypto, а не GitHub Pages как внешняя площадка.

| Группа | Подтверждённое поведение |
|---|---|
| Вход и seed | Отказ без входа и при неверном пароле, выход, демоданные, соль и хеш вместо открытого пароля |
| Учебные пользователи | Раздельные реестры через адаптер, запрет дубликата логина, одинаковый номер в разных реестрах |
| Груз и журнал | Создание, дубликаты, обновление, обратный порядок истории, возвращаемые объекты не меняют хранилище |
| CSV | BOM, семь колонок, экранирование, кириллица, обработка значений с префиксами формул |
| Повторное открытие | Данные и сеанс сохраняются при перезагрузке, срок сеанса восемь часов |
| Неверный ввод | Ошибки не меняют сохранённое состояние |
| Ошибки хранилища | Понятное сообщение при отказе, повторная инициализация, повреждённые данные не сбрасываются автоматически |
| Неудачная запись | Старое состояние сохраняется, неудачная регистрация не оставляет новый сеанс |

Это учебное разделение внутри адаптера. Пользователь браузера может изменить localStorage и sessionStorage напрямую, поэтому тесты не доказывают серверную авторизацию или защищённость демоверсии.

## Проверка статического сайта в браузере

Раздача файлов: `python3 -m http.server 8090`. Проверенный адрес: `http://127.0.0.1:8090/?mode=browser`.

Через CUA выполнены:

1. Вход `demo / demo12345`.
2. Создание груза `PAGES-2026-01`.
3. Поиск созданной записи.
4. Смена статуса на «На таможне», добавление комментария и просмотр журнала.
5. Перезагрузка страницы с сохранением записи.
6. Нажатие «Скачать CSV» и наблюдение сообщения об успешном запуске скачивания.

Сохранение файла в папке загрузок и открытие скачанного CSV отдельно не проверялись. Формирование содержимого CSV подтверждено автоматическими тестами.

## Ограничения проверки

- Проверки не заменяют аудит безопасности или нагрузочные испытания.
- Широкий набор устройств и браузеров не проверялся.
- Время в браузерном варианте зависит от часов устройства, в серверном от часов сервера.
- Нет реальных API перевозчиков, GPS, ETA и юридических таможенных решений.
