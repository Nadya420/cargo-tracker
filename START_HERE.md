# Как открыть готовую работу

В проекте два варианта приложения. Они показывают одинаковые операции, но по-разному хранят и защищают данные.

## 1. Серверная версия на Python

1. Распакуйте архив целиком.
2. На macOS запустите `start.command` либо в терминале в папке проекта выполните `python3 server.py --demo`.
3. На Windows запустите `start.bat` либо выполните `py -3 server.py --demo`.
4. Откройте http://127.0.0.1:8080.
5. Войдите: **demo / demo12345**.

Здесь работают Python API, SQLite, серверная проверка входа и времени событий. Терминал должен оставаться открытым. Остановка: `Ctrl+C`. База создаётся при первом запуске, данные сохраняются между запусками, после перезапуска нужно снова войти.

## 2. Сайт для GitHub Pages

Новая версия ещё не опубликована. Планируемый адрес: `https://nadya420.github.io/cargo-tracker/`. Он не заявляется как проверенная работающая ссылка. Для публикации нужны загрузка в репозиторий студентки и настройка Pages на `main` / `/(root)`.

Для локального показа этой версии:

```bash
python3 -m http.server 8090
```

Откройте http://127.0.0.1:8090/?mode=browser и войдите **demo / demo12345**. В этом режиме Python только раздаёт статические файлы. Логика работает в браузере, записи лежат в localStorage, время берётся с устройства. Данные не передаются в SQLite и не синхронизируются на других компьютерах. Вход учебный, его нельзя считать защитой от владельца браузера. Используйте только вымышленные сведения.

## 3. Презентация и защита

Откройте `presentation.html` двойным щелчком. Файл самодостаточный, интернет и сервер ему не нужны. Внутри 19 слайдов, анимации, встроенные снимки и заметки докладчику.

- Влево / вправо или пробел: перелистывание.
- «Все слайды» или G: оглавление.
- «Заметки» или N: подсказки. Скройте их перед показом на проекторе.
- M: переключение анимации.
- F: полноэкранный режим, если браузер его поддерживает.
- «Печать / PDF»: печать всех 19 слайдов, анимации отключаются. Проверьте раскладку в предпросмотре.

Все слайды идут последовательно. Кнопки и отдельного режима «Защита 4 минуты» нет.

Порядок показа: `PRESENTATION_GUIDE.md`. Текст выступления: `DEFENSE.md`. Вопросы: `TEACHER_QA.md`. Требования: `REQUIREMENTS.md`. Полная инструкция запуска и публикации: `README.md`.
